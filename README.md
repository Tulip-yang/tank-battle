# 坦克大战（最小可玩版）

用 HTML + JavaScript + Canvas 实现的经典坦克大战小游戏，作为 vibecoding 练习项目。

## 如何运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 射击 |
| P / Esc | 暂停 |
| R | 游戏结束后重新开始 |

## 游戏规则

- 消灭全部 5 个敌方坦克即可获胜
- 有 3 条命，被敌方子弹击中扣 1 条，生命归零游戏结束
- 每消灭一个敌人 +100 分
- 被击中后坦克会在底部重生，并短暂无敌

## 项目结构

```
tank-battle/
├── index.html      # 入口页面
├── css/style.css   # 页面样式
└── js/
    ├── config.js   # 游戏参数（速度、尺寸、数量）
    ├── map.js      # 地图数据（二维数组）与碰撞检测
    ├── tank.js     # 通用坦克类（玩家和敌方共用）
    ├── bullet.js   # 子弹逻辑
    ├── enemy.js    # 敌方坦克 AI（出生、移动、射击）
    └── game.js     # 主循环、键盘输入、碰撞、计分、游戏状态
```

## 设计要点

- **数据驱动地图**：地图用 20×20 二维数组表示，改数组即改关卡
- **类复用**：`Tank` 类被玩家和敌人共用，控制与表现分离
- **主循环**：`update` 改数据、`draw` 画画面，每帧由 `requestAnimationFrame` 驱动
- **碰撞**：移动前"先试再走"，坦克与坦克、坦克与墙互不穿透
- **计时单位统一为秒**：`dt` 为帧间隔秒数，所有冷却/无敌时间都以秒计
